# Module Reports

每个 CORE 学习过程中在此目录创建：

`docs/modules/<MODULE_ID>/MODULE_REPORT.md`

必须从 `docs/templates/MODULE_REPORT.md` 复制结构，并写入真实 evidence。跨聊天继续学习时，先读取所有 prerequisite reports 和当前模块报告。

模块只有在 `practice + real evidence + report + interview` 全部完成、`LEARNING_STATUS.md` 已更新且形成一次合理 commit 后，才能标记 `Completed`。此目录不预造任何模块完成报告。
