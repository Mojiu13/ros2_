# DLC-SIM-GRAPHICS｜Gazebo / RViz Graphics 排障

> DLC-B · 不影响 CORE completion / Application Gate

## Trigger Conditions

Gazebo/RViz 黑屏、GUI 卡死、software rendering、GPU passthrough 或 OpenGL renderer 实际异常。没有真实 graphics 问题不要学。

未满足 Trigger 时不要学习；只有学习者明确说“进入 DLC-SIM-GRAPHICS”才解除 DLC LOCK。

## Prerequisites

ENV-01；真实 graphics 故障

## 为什么不在 CORE

不学习它不会阻止当前 ROS2 机械臂完整项目继续推进，或只对特定岗位、真实问题和更深工程场景有价值。

## Scope

Intel/AMD/NVIDIA 容器访问、OpenGL renderer、Mesa/EGL/GLX 所需最小诊断、display protocol、software rendering detection。

## 学习方式

仍采用运行→观察→修改→单一故障→修复→总结，但不得反向扩大 CORE。完成后返回触发它的 CORE/项目问题。

## Deliverables

## Exit Criteria
