# DLC-JOB｜求职强化与压力面试

> DLC-B · 不影响 CORE completion / Application Gate

## Trigger Conditions

已经投递，真实面试反馈显示题库、系统设计、C++/ROS 高频题或压力排障需要强化。

未满足 Trigger 时不要学习；只有学习者明确说“进入 DLC-JOB”才解除 DLC LOCK。

## Prerequisites

JOB-01 或已开始真实面试

## 为什么不在 CORE

不学习它不会阻止当前 ROS2 机械臂完整项目继续推进，或只对特定岗位、真实问题和更深工程场景有价值。

## Scope

大规模模拟面试、C++/ROS 高频题、系统设计追问、debugging pressure interview、resume iteration。

## 学习方式

仍采用运行→观察→修改→单一故障→修复→总结，但不得反向扩大 CORE。完成后返回触发它的 CORE/项目问题。

## Deliverables

按真实反馈维护的题库、模拟记录和简历迭代。

## Exit Criteria

触发问题已解决或目标能力有真实证据；明确记录适用边界，并回到 CORE/求职项目。

## DLC 面试

只考本 DLC 实际完成内容；不得把本 DLC 题目加入 CORE 模块面试或 Application Gate。

## 新对话恢复

读取 README、dlc/README.md、dlc/DLC_INDEX.md、本文件、Trigger 证据、相关 CORE module/report 和项目真实文件；不得依赖上一聊天记忆。
