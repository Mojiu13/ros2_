# DLC-ENV-ADV｜Docker、Linux 与设备环境深化

> DLC-B · 不影响 CORE completion / Application Gate

## Trigger Conditions

稳定 ros2-dev 无法满足 native fallback、USB/serial/device、复杂 GPU 或多 container 需求；出现真实环境阻塞。

未满足 Trigger 时不要学习；只有学习者明确说“进入 DLC-ENV-ADV”才解除 DLC LOCK。

## Prerequisites

ENV-01；明确环境问题

## 为什么不在 CORE

不学习它不会阻止当前 ROS2 机械臂完整项目继续推进，或只对特定岗位、真实问题和更深工程场景有价值。

## Scope

多 container、native fallback、device passthrough、Docker troubleshooting、GPU container 深化、权限与环境差异；不以兴趣触发。

## 学习方式

仍采用运行→观察→修改→单一故障→修复→总结，但不得反向扩大 CORE。完成后返回触发它的 CORE/项目问题。

## Deliverables

环境诊断、选型理由和可复现修复。

## Exit Criteria

触发问题已解决或目标能力有真实证据；明确记录适用边界，并回到 CORE/求职项目。

## DLC 面试

只考本 DLC 实际完成内容；不得把本 DLC 题目加入 CORE 模块面试或 Application Gate。
