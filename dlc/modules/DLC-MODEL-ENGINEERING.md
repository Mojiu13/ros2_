# DLC-MODEL-ENGINEERING｜机器人模型工程化

> DLC-B · 不影响 CORE completion / Application Gate

## Trigger Conditions

未满足 Trigger 时不要学习；只有学习者明确说“进入 DLC-MODEL-ENGINEERING”才解除 DLC LOCK。
