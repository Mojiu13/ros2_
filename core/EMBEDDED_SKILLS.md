# Embedded Skills｜Linux、Git、CMake / ament

这些能力不独立形成长期 CORE 模块；只在当前任务需要时学习最小部分。

## Linux

`pwd/cd/ls`、`cp/mv/rm`、`cat/less/tail`、`grep/find`、`env/export/which`、`ps/kill`、`chmod/chown`、`apt`、基础 bash。高级 shell/systemd/networking：`DLC_REF: DLC-TOOLS`。

## Git

每个 CORE 自然使用 status、diff、add、commit、log、branch/switch、restore、gitignore；完成模块应产生一次真实 commit。rebase/cherry-pick/bisect/submodule：`DLC_REF: DLC-TOOLS`。

## CMake / ament

第一次需要可执行文件时学 add_executable；需要依赖时学 ament_target_dependencies；需要 launch/config 时学 install；需要 interface 时学 rosidl。高级 CMake：`DLC_REF: DLC-TOOLS`。
