# Fast / Standard / Advanced 路线

路线按技能依赖定义，不承诺固定天数。工作量只使用 S/M/L/XL。

## Fast Track：求职优先

顺序：ENV-01 → ROS-01 → ROS-02 → ROS-03 → SYS-01 → MODEL-01 → SIM-01 → CTRL-01 → CTRL-02 → MOVEIT-01 → MOVEIT-02 → INT-01 → APP-01 → DBG-01 → TEST-01 → DOC-01 → JOB-01。

Fast 不能跳过：C++、Gazebo、直接 trajectory、MoveIt 编程闭环、独立故障排查、测试报告和项目文档。可以暂缓 MODEL-02、ROS-04、CTRL-03、MOVEIT-03、APP-02 及全部 P2。

## Standard Track：基本独立工作

完成全部 P0 后，按依赖加入 MODEL-02、ROS-04、CTRL-03、MOVEIT-03、APP-02，再回到 DOC-01/JOB-01 更新最终证据。目标是能承担模型/config 修改、应用开发、常见故障、测试和文档。

## Advanced Optional：岗位定向加分

- ADV-01：适合 controller/实时执行链追问较多的岗位。
- ADV-02：适合 ros2_control 框架或底层控制岗位。
- ADV-03：适合 MoveIt 规划应用与参数优化岗位。

## P3 暂不学习

DDS 内部实现、executor 源码、MoveIt 全源码、复杂实时控制、高级动力学/控制、强化学习、Isaac Lab、视觉伺服、触觉、CUDA/TensorRT、具身大模型。目标岗位变化后才重新评估。
