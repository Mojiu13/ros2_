# CORE / DLC 模块面试规则

## CORE 面试

每个 CORE 结束前问 5–8 题，覆盖概念边界、系统角色、CLI/证据、故障排查和项目表达。先出题，学习者回答，评价并重答，最后才整理标准答案。

只考完成当前工作所需内容。禁止在 CORE 面试考 DDS/executor internals、高级 quaternion/DH/Jacobian、controller source/realtime、Docker internals、advanced testing/documentation、OMPL 或其他 DLC。

## DLC 面试

只有明确进入并完成某 DLC 后，才在其独立记录中提问；DLC 成绩不影响 CORE completion 或 Application Gate。

## 完成

代码跑通、故障/回归、deliverables、无提示复述和面试缺一不可；答案必须与真实项目证据一致。
